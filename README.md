# Spark Worlds — concept and storyboard package

Prepared October 18, 2026 from our product-planning conversation.

## What's inside
- `01-product-brief.md`: product vision, audiences, gameplay loop, scope, and unresolved decisions.
- `02-story-and-characters.md`: world lore, narrative arc, cast, character design principles, collectibles.
- `03-end-to-end-experience.md`: parent discovery through first play, scene-by-scene.
- `04-prototype-and-technical-plan.md`: prototype roadmap and suggested 2D-to-3D production pipeline.
- `05-research-and-validation.md`: storytelling/game design principles to research, validation hypotheses, playtesting.
- `storyboard.html`: mobile-friendly, no-JavaScript storyboard; open locally in any modern browser.

## Current state (important)
The concept and flow have been defined conversationally. The included HTML is a newly packaged **clickable storyboard**, not a working 3D game. Visuals are CSS/emoji placeholders. There are no final character illustrations, modeled 3D assets, authenticated parent accounts, voice controls, or playable physics in this package.

Working title: **Spark Worlds** (not yet finalized).

## How to view
Unzip the archive and open `storyboard.html` in your browser. The file needs no server or third-party dependencies.
